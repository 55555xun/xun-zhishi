## 1. 数组创建函数

### 1.1 np.array() —— 自定义创建数组

**语法**

```python
np.array(object, dtype=None, copy=True, order='K', ndmin=0)
```

**参数详解**

- `object`：【必填】数据源，列表、元组、可迭代对象、数组
- `dtype`：【可选】指定数据类型，如`int、float、bool、np.int32、np.float64`，默认自动推断
- `copy`：【可选】是否复制数据，默认 `True`；`False` 复用原数据内存
- `order`：【可选】内存存储顺序，`C`行优先、`F`列优先、`K`保留原顺序
- `ndmin`：【可选】指定数组最小维度，自动补全维度

**示例**

```python
# 强制二维数组、浮点类型
arr = np.array([1,2,3], dtype=np.float32, ndmin=2)
print(arr)  # [[1. 2. 3.]]
```

**⚠️ 避坑点**

- 传入嵌套列表长度不一致会报错，无法创建不规则数组
- `copy=False` 时，修改原列表会影响数组值

### 1.2 np.arange() —— 等差数值数组

**语法**

```python
np.arange(start=0, stop, step=1, dtype=None)
```

**参数详解**

- `start`：起始数值，默认 0
- `stop`：【必填】终止数值，**不包含该值**
- `step`：步长，默认 1，支持小数
- `dtype`：指定数组数据类型

**示例**

```python
arr = np.arange(1, 10, 2)
print(arr)  # [1 3 5 7 9]
```

**⚠️ 避坑点**

- 浮点步长会存在精度误差，优先用 `linspace` 生成均分小数序列

### 1.3 np.linspace() —— 固定数量均分数组

**语法**

```python
np.linspace(start, stop, num=50, endpoint=True, retstep=False, dtype=None)
```

**参数详解**

- `start`：起始值
- `stop`：终止值
- `num`：生成元素总个数，默认 50
- `endpoint`：是否包含终止值，默认`True`
- `retstep`：是否返回步长，默认 `False`
- `dtype`：指定数据类型

**示例**

```python
arr, step = np.linspace(0, 10, 5, retstep=True)
print(arr)   # [ 0.   2.5  5.   7.5 10. ]
print(step)  # 2.5
```

### 1.4 np.zeros() —— 全0数组

**语法**

```python
np.zeros(shape, dtype=float, order='C')
```

**参数详解**

- `shape`：【必填】数组形状，元组格式 `(行,列)`
- `dtype`：数据类型，默认浮点型
- `order`：存储顺序，默认行优先

**示例**

```python
arr = np.zeros((2,3), dtype=int)
print(arr)
# [[0 0 0]
#  [0 0 0]]
```

### 1.5 np.ones() —— 全1数组

参数、用法、格式与 `np.zeros()` 完全一致

### 1.6 np.eye() —— 单位矩阵

**语法**

```python
np.eye(N, M=None, k=0, dtype=float)
```

**参数详解**

- `N`：【必填】行数
- `M`：列数，默认等于 N，生成方阵
- `k`：对角线偏移量，`0`主对角线、正数上对角线、负数下对角线
- `dtype`：数据类型

**示例**

```python
arr = np.eye(3, k=1)
print(arr)
# [[0. 1. 0.]
#  [0. 0. 1.]
#  [0. 0. 0.]]
```

## 2. 数组形状与维度操作

### 2.1 reshape() —— 修改数组形状

**语法**

```python
arr.reshape(shape, order='C')
```

**参数详解**

- `shape`：新形状，整数/元组，支持 `-1` 自动推算维度
- `order`：排列顺序

**示例**

```python
arr = np.arange(6).reshape(2, -1)
print(arr.shape)  # (2, 3)
```

**⚠️ 避坑点**

- 新形状总元素数必须和原数组一致，否则报错

### 2.2 flatten() —— 展平数组（生成新数组）

**语法**

```python
arr.flatten(order='C')
```

**参数**：`order='C'`行展平、`'F'`列展平

**特点**：返回全新数组，修改新数组不影响原数组

### 2.3 ravel() —— 展平数组（引用原数组）

参数同 `flatten`，返回原数组视图，**修改新数组会改变原数组**

### 2.4 np.transpose() / .T —— 数组转置

**语法**

```python
np.transpose(a, axes=None)
```

**参数详解**

- `a`：待转置数组
- `axes`：维度调换顺序，二维数组默认行列互换

## 3. 数组拼接与分割

### 3.1 np.concatenate() —— 通用拼接

**语法**

```python
np.concatenate((a1, a2, ...), axis=0, out=None)
```

**参数详解**

- `(a1,a2...)`：【必填】待拼接数组元组
- `axis`：拼接维度，`0`上下拼接、`1`左右拼接
- `out`：指定输出存储数组

**示例**

```python
a = np.ones((2,2))
b = np.zeros((2,2))
res = np.concatenate((a,b), axis=1)
```

**⚠️ 避坑点**

- 非拼接维度的形状必须完全一致，否则拼接失败

### 3.2 np.vstack() / np.hstack()

- `np.vstack(tup)`：垂直堆叠，等价于 `concatenate(axis=0)`
- `np.hstack(tup)`：水平堆叠，等价于 `concatenate(axis=1)`

### 3.3 np.split() —— 数组分割

**语法**

```python
np.split(ary, indices_or_sections, axis=0)
```

**参数详解**

- `ary`：待分割数组
- `indices_or_sections`：int 均分n份；列表 指定分割索引点
- `axis`：分割维度

**示例**

```python
arr = np.arange(8)
res = np.split(arr, [3,5])
# [array([0,1,2]), array([3,4]), array([5,6,7])]
```

## 7. 条件与逻辑判断函数

### 7.1 np.where() —— 条件筛选

**语法**

```python
np.where(condition, [x, y])
```

**参数详解**

- `condition`：布尔条件数组
- `x/y`：满足条件取x，否则取y；省略则返回满足条件的索引

### 7.3 np.all() / np.any()

- `np.all()`：所有元素满足条件返回 True
- `np.any()`：任意一个元素满足条件返回 True

## 一、数据读写函数（CSV / Excel）

### 1.1 pd.read_csv() 读取 CSV 文件

**语法**

```python
pd.read_csv(filepath_or_buffer, sep=',', header=0, index_col=None, encoding='utf-8', skiprows=0, na_values=None)
```

**核心参数详解**

- `filepath_or_buffer`：必填，文件路径/URL/文件流
- `sep`：分隔符，默认 `,`；制表符文件用 `\t`，自动识别用 `None`
- `header`：指定表头行，`0` 第一行为表头，`None` 无表头
- `index_col`：指定索引列，`None` 不设索引，可传列名/列序号
- `encoding`：编码格式，常用 `utf-8`、`gbk`、`gb2312`
- `skiprows`：跳过前 N 行，或指定跳过行列表
- `na_values`：指定识别为缺失值的字符，如 `['', 'NA', 'null']`

**示例**

```python
# 读取gbk编码、空值识别为NA、跳过首行注释
df = pd.read_csv("data.csv", encoding="gbk", skiprows=1, na_values=["NA", ""])
```

### 1.2 pd.read_excel() 读取 Excel 文件

**语法**

```python
pd.read_excel(io, sheet_name=0, header=0, index_col=None, engine="openpyxl")
```

**核心参数详解**

- `io`：文件路径
- `sheet_name`：工作表，`0` 第一张表，可传表名字符串
- `engine`：解析引擎，xlsx 文件用 `openpyxl`，xls 文件用 `xlrd`

**示例**

```python
df = pd.read_excel("data.xlsx", sheet_name="销售数据", engine="openpyxl")
```

### 1.3 df.to_csv() 导出 CSV

**语法**

```python
df.to_csv(path_or_buf, index=True, header=True, encoding="utf-8", sep=',')
```

**核心参数详解**

- `index`：是否导出行索引，日常使用固定 `index=False`
- `header`：是否导出表头

**示例**

```python
df.to_csv("out.csv", index=False, encoding="utf-8-sig")
```

### 1.4 df.to_excel() 导出 Excel

**语法**

## 三、数据清洗函数（缺失值、重复值、类型转换）

### 3.1 缺失值处理

#### 3.1.1 df.dropna() 删除缺失值

**语法**

```python
df.dropna(axis=0, how='any', thresh=None, subset=None, inplace=False)
```

**参数详解**

- `axis`：`0/rows` 删除行，`1/columns` 删除列
- `how`：`any` 存在缺失即删除，`all` 全部缺失才删除
- `subset`：指定仅根据某几列判断缺失值，例 `subset=["年龄","性别"]`
- `inplace`：`False` 返回新数据，`True` 原地修改原数据

#### 3.1.2 df.fillna() 填充缺失值

**语法**

```python
df.fillna(value=None, method=None, limit=None, inplace=False)
```

**参数详解**

- `value`：填充值，支持数字、均值、字典（多列不同填充）
- `method`：`ffill` 前向填充，`bfill` 后向填充
- `limit`：最大填充数量

**示例**

```python
# 数值列填均值，文本列填未知
df["年龄"].fillna(df["年龄"].mean())
df["性别"].fillna("未知")
```

### 3.2 重复值处理 df.drop_duplicates()

**语法**


**参数详解**

- `subset`：指定根据哪些列判断重复，默认全部列
- `keep`：`first` 保留第一条，`last` 保留最后一条，`False` 删除所有重复

## 七、多表合并函数

**参数详解**

### 7.2 pd.merge() 表关联（SQL JOIN）

**语法**

```python
pd.merge(left, right, on=None, how='inner', left_on=None, right_on=None)
```

**参数详解**

- `left/right`：左表、右表
- `on`：两张表共同关联字段
- `how`：连接方式        
  - `inner`：内连接（匹配数据）
  - `left`：左连接（保留左表所有）
  - `right`：右连接
  - `outer`：全外连接
- `left_on/right_on`：两表关联字段名不一致时分别指定

## 八、时间处理函数

### 8.1 pd.to_datetime() 时间转换

**语法**

```python
pd.to_datetime(arg, errors='raise', format=None)
```

**参数详解**

- `errors`：`ignore` 忽略错误，`coerce` 错误值转为 NaT
- `format`：自定义时间格式，例 `"%Y-%m-%d"`

**示例**

```python
df["日期"] = pd.to_datetime(df["日期"], errors="coerce")
```

### 8.2 dt 时间属性提取

**语法**

```python
df["年份"] = df["日期"].dt.year
df["月份"] = df["日期"].dt.month
df["日"] = df["日期"].dt.day
df["星期"] = df["日期"].dt.weekday
```
