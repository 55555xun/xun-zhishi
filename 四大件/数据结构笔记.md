## 线性表

线性表：具有相同数据类型的n(n>0)个数据元素的有序序列。其中n是表长，当n=0时为空表。

​	一般表示为：L=（a1,a2,a3...an)

​	a1是第一个数据元素，an是最后一个数据元素，除了这俩个以外其他每个数据元素都有一个前驱元素和一个后驱元素

要满足以下限制：

​	1.除了第一个和最后一个元素外，每个元素只有一个前驱和一个后继。

​	2.第一个元素没有前驱

​	3.最后一个元素没有后继

用顺序存储存储结构实现的线性表：顺序表（数组）    

用链式存储结构实现线性表：链表（基于指针实现）

### 顺序表

操作：增删改查

增加操作：在顺序表中的某一个位置添加一个数据

​	（1）末尾添加

​	（2）在指定位置i添加（i < =len)

查找操作：在顺序表中找到k所在的位置（下标），如果不存在就返回-1

删除操作：在顺序表中删除数据k

​		（1）先调查找，确认k是否存在

​		（2）若k存在，执行删除 

​		（3）len--

更改：数据k改为数据k1

顺序表的优缺点：

优点：支持随机存取  基地址+偏移量（data+i)  

​		存储密度高

缺点：插入 删除操作过于繁琐

> 适用于数据稳定

### 链式存储

线性表的链式存储结构：用链式存储结构实现的线性表就叫（单）链表

**链表**：结点和结点之间相连

  	[数据域]+[指针域（下一个数据所作结点的地址）]

​	1.定义一个结点：结构体

​	2.头指针：保存链表中第一个结点的地址的指针，头指针通过标记第一个结点，从而标记整个链表因此用头指针的名字命名整个链表

​	3.节点分开命名

​	4.带头结点的单链表 /不带头结点的单链表

​		头节点：在带头节点的链表中的第一个结点

​		首元结点：保存线性表中的额一个数据的结点

​		第一个节点：头指针指向的结点

​	5.有一个链表L

```c
Node*p=L;

Node*p=L->next;
```

**为什么有头节点？**

​	1.统一了首元结点和后面其他结点的操作

​	2.把空链表和非空链表的操作统一了

#### 单链表

单链表的**操作**：增删改查

​	1.初始化一个空单链表

​	2.添加数据

​		（1）**头插法**：每次都在头节点后面插入一个结点，每个新插入的结点都做首元结点

​			  **特点**：链表中的数据的顺序和插入的顺序相反

​		（2）**尾插法**：每次在最后面插入一个新的结点，每个新插入的结点都做最后一个结点

​		（3）在指定位置插入数据：在数据x后面插入数据k

​	3.查找：遍历每个节点

​	4 .删除：删除k所在的结点

​	5.改:数据x改为数据k

​		**先查后改**

​	优点：灵活 便捷

​	缺点：不支持随机存取，只能遍历数据

##### 循环单链表

单链表首尾相接。尾结的next指针域保存头结点的地址

操作和单链表的造作思路一样的，唯一的区别就是涉及尾结点next指针域的地方要变动一下

```c
{

	//if(head==NULL)
	head->next=head;
	return head;
}
//增：在链表L中添加一个数据k

//把L看成链表，

{

	s->next=L->next;//结点s的指针域指向原来的首元结点 头结点L度指针域中保存了原首元结点的地址
```

##### 循环双链表

双链表首尾相接。尾结点的next指针域保存头结点的地址。头结点的pre保存尾结点的地址

操作和双链表的操作思路一样。唯一区别就是涉及到头结点的pre。尾结点的next要变动一下

```c
}Node,*LinkList;
Node* InitLink()
{
	Node* head=(Node*)malloc(sizeof(Node));
	//if(head==NULL)
	head->next=head;
    head->pre=head;
	return head;
}
LinkList Head_insert(LinkList L,int k)
{
    Node* s=(Node*)malloc(sizeof(Node));
	//if(s==NULL)
    s->data=k;
    s->next=L->next;
    L->next->pre=s;
    L->next=s;
    s->pre=L;
```

### 二叉树

非线性的逻辑结构

在二叉树中，每个节点的度不超过2

两种特殊的二叉树：

1.满二叉树：二叉树中的每个（非叶子）结点的度都是2，并且叶子节点都在同一层

2.完全二叉树：把一颗二叉树从下至上，从右至左删除若干个节点，剩下的部分称为完全二叉树

1一定是2，2不一定是1

----------

二叉树的性质：（公式）

假设有一颗含n个结点，k层的二叉树

1.在该树的第i层，最多有2^(i-1)个节点（根结点是第一层）

2.如果k是固定的，最多2^k-1个节点（根结点是第一层）

3.在任意一颗二叉树中，叶子结点的的个数比度为2度的个数多一个  n0=n2+1

4. n个节点的完全二叉树的深度k是floor(log(n+1))   ceil(log(n+1))
5. 给一颗完全二叉树按照从上至下 从左至右 进行编号，编号从0开始，编号为i的节点，其父亲为i/2. 两个孩子分别是2*i      2*i+1

----------

如果p为空，栈非空，栈顶的左子树访问完了，栈顶出栈q。先访问q,p=q->r访问q的右

#### 线索化

能够快速找到一个结点在某遍历序列中的前驱后继

 中序线索化：

利用上二叉树中的n+1空指针域，去保存其所在结点的（中序遍历序列中）前驱或者后继。

空的左指针域：保存前驱

空的右指针域：保存后继

保存在遍历序列中的前驱或后继的指针称为线索

1如何添加中序线索

执行中序遍历引入pre,保存刚刚遍历过的结点

当我们正在访问x结点的时候，和pre构成一对前驱后继关系：

x是pre的后继，if(pre->r==NULL)pre->r=x

pre是x的前驱，if(x->l==NULL)x->l=pre

2.如何根据线索去找某结点的前驱o后继

中序遍历序列的特点 左 根 右

（1）前驱

if(p->lflag==1)p->l就是前驱，输出p->l->data

else 去p的左子树中找最靠右的结点。q=p->l,while(q->rflag==0&&q->l!=NULL)q->q->r



（2）后继

if(p->rflag==1)p->r就是后继。输出p->r->data

else 去p的右子树中找最靠左的结点。q=p->r,while(q->lflag==0&&q->l！=NULL)q=q->l

### 二叉排序树-BST

是一种特殊的二叉树,在普通的二叉树的基础上增加了"顺序性"的限制。

定义:在二叉树基础上,增加顺序性的约束:

(1)如果树中的一个结点,其左子树非空,那么左子树中的数居都要小于该结点的数据

(2)如果树中的一个结点,其右子树非空,那么右子树中的数据都要大于该结点的数据
反之亦可

BST性质:中序遍历序列是有序的***

优势：加快数据查找

存储方式:用BST存储

操作:查找插入数据(建树)删除数据

1.在中序遍历序列升序的BST上查找数据x

从根结点开始查找,结点和x比较,如果相等找到了,如果不相等就往孩子结点上走:

×<结点.往左走

x>结点往右走

走到NULL,没找到。

基于非递归实现:只需要引入一个指针P帮我们进行遍历即可

基于递归实现:大问题缩小为小问题递归调用

2.在中序遍历序列生序的BST上插入数据x

创建结点保存x并且把结点插入到树中

基于非递归:1.创建结点s保存x2.查找s应该在的位置3.把s插入

3.在中序遍历序列升序的BST上删除数据x

第一步:先找到x所在的结点以及x的父亲结点

(1)度为0/1的结点---父亲

第二步:找到x的孩子ch。把pre指向p的指针改为指向ch。删除0(注意p为根结点时
更新root)

(2)度为2的结点---父亲+左右孩子

第二步:找x的中序遍后继结点h,顶替x的位置(更新p的数据国域即可）

直接在p的右子树中 删除h即可---删除一个度为1/0的结点

### 二叉平衡树---AVL树

某结点平衡因子:该结点左右子树的高度差-------->结点的高度

AVL树的平衡性:对每个节点的平衡因子做出限制 每个节点的平衡因子的绝对值<=1.

AVL目的:避免退化为斜树,一定能提高我们查找的效率

 失衡节点:左右子树高度差超过1的节点

AVL树操作:基于BST的操作过程的

如何进行操作:查找 插入 删除

1.查找:在一棵AVL树上查找某个数据x
和BST的查找一模一样

进行插入或删除之后要仍然保持顺序性和平衡性:为了保证顺序性,应该先按照BST的操作进行。再判断是否满足平衡性，如果不满足平衡性,要调整？

不平衡时应该怎么调整?
之所以不平衡是因为高的子树比矮的子树节点多,想办法在保证顺序性的同时,从高的那边拿一些节点给矮的那边。------旋转

(1) 以 x 为根的子树，x 失衡，x 左子树比右子树高右旋

1.y=x->l;// 旋转之前 y 是 x 的左孩子

2.x 的左孩子会变成 y->r

x->l=y->r

3.y 的右孩子变成 x

y->r=x

x->h=1+maxx (Geth (x->l),Geth (x->r))

y->h=1+maxx (Geth (y->l),Geth (y->r))

return y;



2.在二叉平衡树中插入一个数据x(插入一个结点)

(1)执行BST的插入过程---满足了顺序性

(2)判断也没有出现失衡节点:可能存在多个失衡节点,对应多棵失衡子树,要从最小失衡子树开始调整。

递归版本的插入函数,递归返回的顺序刚好是小子树到大子树的顺序。

因此只需要在调用完递归函数之后,返回到本层时对本层的根结点root进行失衡判断并调整即可。

最小失衡子树的失衡情况有4种:

在失衡节点x的左孩子的左子树中插入新结点,导致失衡(LL夫衡)----->对失衡节点x进行一次右旋

在失衡节点x的左孩子的右子树中插入新结点,导致失衡(LR夫衡)---->先对×->l左旋,然后再对失衡节点x进行右旋

在失衡节点x的右孩子的右子树中插入新结点,导致失衡(RR失衡).----->对失衡节点x进行一次左旋

在失衡节点x的右孩子的左子树中插入新结点,导致失衡(RL夫衡)----->先对x->r右旋,再对失衡节点x左旋

3.删除---看成插入的4种失衡情况

左边删除导致的失衡等同于右边插入导致的失衡

右边删除导致的失衡等同于左边插入导致的失衡

(1)执行BST的删除操作

(2)检测失衡,进行旋转调整---要把删除看成对应的插入导致的失衡情况

r->left > r->right RL

如果是在x的右子树中删除的k,导致x失衡,可以看作是在x左子树中擂入一些结点导致的失衡---LL LR

如何判断是LL还是LR:令l是x的左孩子 比较l->left>=l-> right.LL

### 哈夫曼树

基础概念：

1.结点的路径长度:根结点到该结点所经过的边数

2.树的路径长度:所以结点的路径长度之和

外路径长度:所有的叶子节点的路径长度之和

3.结点的带权路径长度:给树中的每个节点加一个权值

一个结点的带权路径长度=该结点的路径长度*该结点的权值

4.树的带权路径长度WPL:给树中的每个节点加一个权值

树的带权路径长度=所有叶子节点的带权路径长度之和

最优二叉树:

给定n个带权值的节点,要求用这n个结点做叶子节点,额外添加n-1个结点,可以构造出多种形态的含有2n-1个结点的二叉树,其中WPL值最小的,称为最优二叉树---哈夫曼曼树

  n个带权值的节点做叶子。额外添加n-1个结点可以构造出很多棵二叉树。
哈夫曼算法:

一开始认为n个结点就是n棵树,进行n-1次两两合并,最终就就会变成一棵树

合并时:选择两棵树,加一个结点,让这两棵树做该结点的左右子树,新加的根结点的权值时原来两棵树根结点的权值之和。

每次选择根结点权值最小两棵树合并。

```c
void find(HuffmanNode*  tree,int x,int* s1,int* s2)
{//在tree[0]~~tree[x]中找权值最小的两个根结点
	//先找最小的
	int minn=0;//保存找到的权值最小的根结点的下标
    for(int i=0;i<=x;i++)
	{
		if(tree[i].fa==-1)
		{
			minn=i;
			break;
		}
	}
	for(int i=0;i<=x;i++)
	{
		if(tree[i].fa==-1&&tree[i].weight<tree[minn].weight)
		{
			minn=i;
		}
	}

	//找第二小的

			break;
		}

		}
	}
```

### 图的遍历

图:确定起始顶点V---都行

深度优先遍历 Depth First Search DFS

深度:遍历的顺序 会沿着路径逐渐远离V,直到死胡同,再回到上一个顶点,重新选一个方向--->递归

1.先选定一个起点V。

2.对V进行深度遍历,DFS(v),访问V并标记,遍历V的邻接点,选一个未被访问的邻接点j,DFS(j),当DFS

(j)结束并且返回到v后,继续跳一个V的未被访问的邻接点,进行DFS,直到V的所有的邻接点都被访问完,返回V的上一层。

```C
//Kruskal算法的时间复杂度 取决于所选用的排序算法的时间复杂度。
//边集数组存图
int n,m;
typedef struct
{
	int u,v;//无向边的两个端点
	int w;//边权
}Edge;
Edge e[10005];
int f[105];
void Sortt(int l,int r)
{
	//选择排序
	int minn;
	Edge t;
	for(int i=l;i<r;i++)
	{
		//i～～r之间找到最小的 和i位置交换
		minn=i;
		for(int j=i;j<=r;j++)
		{
			if(e[j].w<e[minn].w)
			{
				minn=j;
			}
		}
		t=e[i];
		e[i]=e[minn];
		e[minn]=t;

	}
}
int Find(int x)
{//路径压缩 找x所在集合的根结点
	if(f[x]==x)return x;
	else  return f[x]=Find(f[x]);
}
void Kruskal()
{
	for(int i=0;i<n;i++)

		f[i]=i;//初始化并查集
	}

	for(int i=1;i<=m;i++)
	{
		//判断第i条边是否可选
		//e[i].u  e[u].v
		fu=Find(e[i].u);
		fv=Find(e[i].v);
		if(fu!=fv)
		{//u和v不连通，可选
			sum+=e[i].w;
			f[fv]=fu;//合并 注意
			cnt++;
			printf("%d---%d: %d\n",e[i].u,e[i].v,e[i].w);
		}
		if(cnt==n-1)break;
	}
	printf("%d\n",sum);

}

{

	for(int i=1;i<=m;i++)
	{
		scanf("%d %d %d",&e[i].u,&e[i].v,&e[i].w);
	}
```

### Prim算法

Prim算法：从加点的角度，来构造最小生成树

1.保证树形结构:即无环

从一个点开始,逐渐的把所有的点加入到生成树中。用n-1条边把剩下的n-1个点依次连接到生成树上,只要每条边都能连接一个新点到生成树,就不会出现环,最终肯定是树形

把点分为两类:

1.已经加入到生成树上的点

2.还未加入到生成树上的点

2.保证边权和最小:

每次都选离生成树最近的还未加入到生成树上的点。------>每次都选离dist值最小并且·flag==0的点。

点x到生成树到距离:点x在原图中肯定和生成树中的某些点之间有边,这些边的边权称为点x到生成树到距离。

点x到生成树到最小距离:点x在原图中肯定和生成树中的某些点点之间有边,其中最小的边权,称为点到生成树到最小距离。

dist[x]=w:当前,点x到生成树的最短距离是w

点到生成树的最短距离是可能会变小

思路：

思路:

初始化:flag[i]=0 dist[i]=00

1.任选一个点x,dist[x]=0

2.循环n次:选一个dist值最小且flag==0的点p,通过最小边权的边把p加入到生成树中flag[p]=1，再更新p的还未加入到生成树中的邻接点j到生成树到最小距离dist[j]=min(dist[j], p-w--j)

### 最短路径

 基本概念

图中两点间的路径长度/距离：无权图--路径上的边数  带权图---路径上边的边权之和

两点间的最短路径/距离：两点之间可能有多条路径，其中距离/路径长度 最短的称为最短路径

无权图求最短路径的方法：BFS（单源）

带权图求最短路径的方法：

(1)单源最短路径问题:给出一个图,假设图中有n个点,求从固定的起点s到其他n-1个点到最短路径

 Dijkstra算法----贪心-----》不可用于带负数边权的图

找路径x--->y

两点之间最简单的路径是两点之间直接连一条边的路径(如果两点之间间没有边相连可以看成是有一条边权为无穷大的边相连)

该路径是最短的吗?不一定。如果不是最短的,此时最短路径应该是是什么样子?

那么最短路径应该会经过其他中转点。

先姑且认为两点之间直连路径是最短路径。然后我们不断找中转点,看是否可以经过中转变得更短,最终得到真正的最短路径。

dist [x]= len;//当前,起点s到x的最短距离是 len

dist [x]的初始值:g[s] [x]

用x的邻接点j做中转点更新dist[x]
if(dist[j]+g[j][x]<dist[x])dist[x]=dist[j]+g[j] [x]

求起点到多个终点的最短路径

先确定s到谁的最短路径/哪个点为终点的最短路径最最先确定出来？

起点s到离s最近的邻接点的最短路径一定是直连的边---》

s到终点的最短路径一定包含s到中转点的最短路径,因此一旦某个点点最短路径确定了,那么我们就可以用其做中转地更新起邻接点的最短路径。

#### Dijkstra算法:邻接矩阵存图

dist[x]的初始值:g[s] [x]
标记数组flag[x]=1起点到该点的最短路径已经确定,==0还未确定
pre数组记录路径:pre[x] 在起点s到j到最短路径中x到上一个点是j
1.dist[s]=0, flag[s]=1
2.循环n-1,每次确定一个点的最短路径:dist值最小并且flagt=0的点
就可以用该点做中转点更新其flag==0的邻接点的最短路径。

```c
#include<stdlib.h>
#include<string.h>
#define INF 10001
//n（<=100）个点,m条边的带权(边权<10000)无向图，求起点s到其他点的最短路径。//保证起点一定能走到其他点

//邻接矩阵
int n,m;

void Dijkstra(int s)
{//O(n^2)
	dist[s]=0;
	flag[s]=1;//起点自己到自己的最短路径不需要求
	//初始化dist数组 --->把起点的邻接点的最短路径 更新为直连的边
	for(int i=0;i<n;i++)
	{
		if(i!=s&&g[s][i]<INF)
		{
			dist[i]=g[s][i];
			pre[i]=s;//直连路径中 i的上一个点是s
		}

	}
	int minn;//当前离起点最近的点的编号
	int t;//s到minn的最短距离
	for(int i=1;i<n;i++)
	{
		minn=-1,t=INF;
		for(int j=0;j<n;j++)
		{
			if(flag[j]==0&&dist[j]<t)
			{
				t=dist[j];
				minn=j;
			}
		}
		//起点到minn的最短路径可以确定
		flag[minn]=1;
		//用minn做中转点更新flag==0邻接点
		for(int j=0;j<n;j++)
		{
			if(flag[j]==0&&dist[minn]+g[minn][j]<dist[j])
			{
				
				dist[j]=dist[minn]+g[minn][j];
				pre[j]=minn;//记录路径
				

			}
		}

	}

}

		{
			g[i][j]=INF;
			if(i==j)g[i][j]=0;//注意
		}

	}
	int x,y,w;
	for(int i=1;i<=m;i++)
	{
		scanf("%d %d %d",&x,&y,&w);
		g[x][y]=g[y][x]=w;
	}
	int s;

		int p=pre[i];
		while(p!=-1)
		{
			printf("%d ",p);
			p=pre[p];
		}
		printf("\n");

	}
	
	return 0;
}
```

### 拓扑排序

有向无环图:Directed Acyclic Graph--->DAG图

树形结构:可以看成特殊的图

可以用有向无环图去表示项目/工程/流程

AOV网(Activity On Vertex):用顶点表示活动,用有向边表示活动之间的先后次序的有向无环图,称为用项点表示活动的网。

拓扑序列:是基于AOV网得出的一个顶点序列,是完成该AOV网所表示的项目的先后顺序

如果vi到vj有一条路径,那么在序列中vi一定排在vj之前。

拓扑排序:用于得出拓扑序列的的算法/思路,称为拓扑排序

如果要想做一个活动就得保证其前置活动都已经做完了---》第一个做的活动一定是没有前置活动的----》没有入边---》入度为0

首先找入度为0的点,入度为0的点一定是最先可以做的,先加入到拓扑序列中

当我们每做完一个活动,这个活动对应的点以及出边就可以捌掉。每次都去找一个入度为0的点加入到拓扑序列中即可。

拓扑排序代码流程:

引入入度数组ind[i]=w//i点的入度是w

引入一个栈保存入度为0的点

先遍历入度数组把一开始就是0的点入栈
循环n次:(1)出栈,得到一个入度为0的点,加入到拓扑序列中,(2)把该点的出边邻接点的入度-1,如果减到0就入栈。

逆拓扑序列:要先做完所有的后置活动才能做该活动----》和拓扑序列刚好相反

1.求拓扑序列,然后逆转

2.引入出度数组outd[i]=w//i点的入度是w

引入一个栈保存出度为0的点

先遍历出度数组把一开始就是0的点入栈
循环n次:(1)出栈,得到一个出度为0的点,加入到逆拓扑序列中,(2)把该点的入边边邻接点的出度-1,如果减到0就入栈。

3.建立反图,反图的拓扑序列就是原图的逆拓扑序列

#### 关键路径

基础概念:

1.DAG有向无环图

2.AOV网:用顶点表示活动,用边表示活动之间的顺序的有向无环图。

3.AOE网:用边来表示活动的带权有向无环图。边权表示活动的持续时间。顶点表示事件,事件的发生标志着活动的开始或者结束。也是用于项目/工程管理中

活动:一个完整的过程,会持续一段时间。活动的开始结束

事件:瞬间发生的一个动作。事件是否发生

活动的最晚开始时间LTE(Latest Time of Edeg)

关键活动:没有拖延的时间余量ETE=LTE

非关键活动:有可拖延的时间余量ETE!=LTE

### 直接插入排序

主要思想将乱序区挨个插入有序区中的合适位置

一开始认为有序区是a[1],乱序区是a[2]~~a[n]

循环n-1次,执行n-1趟排序:每次把乱序区中的第一个数据,插入到有序区中的对应位置。

假设乱序区的第一个数据是x

(1)倒着遍历有序区,在有序区中找到第一个小于等于x的位置j,j+1位置就应该是x在的位置

(2)空出j+1位置,把j+1到有序区的最后一个位置挨个后移

(3)a[j+1]=x

有序区扩大乱序区缩小

第i趟排序有序区[1,i]乱序区[i+1,n]

稳定

优化:第(1)(2)步可以合并

### 希尔排序（缩小增量排序）

思路：先将所有待排序的数据分组，对每组单独进行直接插入排序，实现整体基本有序，最后再对所有的数据进行一次直接插入排序

```c
#include<stdio.h>
#include<stdlib.h>
int n,a[105];
int main()
{
	scanf("%d",&n);
	for(int i=1;i<=n;i++)
	{
		scanf("%d",&a[i]);
	}
	//希尔排序:时间复杂度 平均时间复杂度O(n^1.3),最坏时间复杂度O(n^2)  就地排序  不稳定
	int k=0;//排序的趟数
	int x,j;
	for(int d=n/2;d>=1;d=d/2)//枚举增量d（d也是组数）
	{
		k++;
		//从第一组的第2个数据开始排序 a[1+d]
		for(int i=1+d;i<=n;i++)
		{
			//a[i] 就是本组中 乱序区的第一个数据 该组的有序区的最后一个位置是i-d
			//i所在组的下标 i，i-d，i-2d
			x=a[i];
			for(j=i-d;j>=1;j-=d)//倒着遍历有序区
			{
				if(a[j]>x)
				{
					a[j+d]=a[j];
				}
				else break;

			}
			a[j+d]=x;
		}

		printf("第%d趟排完的结果:\n",k);
		for(int i=1;i<=n;i++)
		{
		printf("%d ", a[i]);
		}
		printf("\n");



	}
	
	return 0;
	
}
```

### 冒泡排序

执行诺干趟排序：每趟排序时，遍历乱序区，将乱序区相邻的两个数据a[j]a[j+1]进行比较，如果a[j]>a[j+1]交换两者，最终可以把乱序区中最大的数据交换到乱序区的最后面。

```c
#include<stdio.h>
#include<stdlib.h>
int n,a[105];
/*
冒泡排序：对n个数据排序，以排为升序为例

初始时：所有的数据属于乱序区

执行n-1趟排序：每趟排序时，遍历乱序区，将乱序区相邻的两个数据a[j] a[j+1]进行比较，如果a[j]>a[j+1],交换两者。
最终可以把乱序区中最大的数据交换到乱序区的最后一个位置。

最终时：所有的数据属于有序区

*/
int main()
{
	scanf("%d",&n);
	for(int i=1;i<=n;i++)
	{
		scanf("%d",&a[i]);
	}
	//冒泡排序: 最好情况的时间复杂度 O(n)  最坏和平均时间复杂度O(n^2)，稳定的，就地排序
	int t;
	int flag=0;//标记本趟排序中有没有发生交换操作
	for(int i=1;i<=n-1;i++)//枚举排序的趟数
	{
		flag=0;
		//第i趟排序,乱序区的下标范围[1,n-i+1]
		for(int j=1;j<n-i+1;j++)//遍历乱序区 相邻的两个数据比较 交换
		{
			if(a[j]>a[j+1])
			{
				t=a[j];
				a[j]=a[j+1];
				a[j+1]=t;
	    		flag=1;//发生了交换
			}
		}
		if(flag==0)break;
	}

	for(int i=1;i<=n;i++)
	{
		printf("%d ",a[i]);
	}
	printf("\n");
	return 0;	
}
```

### 快速排序

对于待排序区间,会选定一个基准数p,把比p小的数据都交换到p前面把比p大的数据都交换到p后面,使得p在自己位置上。然后再对p前后两部分分别进行快速排序

基准数怎么选取?

选取待排序区间[l,r]的第一个位置做基准:p=a[l];

插空法:如果前面空出位置。就从后往前找一个比p小的数补过去

如果后面空出位置。就从前往后找一个比p大的数补过去

选取待排序区间[l,r]的最后一个位置做基准:p=a[r];

选取待排序区间[1,r]的中间位置做基准:p=a[(1+r)/2];

```c
#include<stdio.h>
#include<stdlib.h>

//快速排序：最好时间复杂度O(nlogn)   平均时间复杂度O(nlogn)   最坏时间复杂度O(n^2)  
//        不稳定   就地排序  空间复杂度O(logn)~~O(n)
void QSort(int a[],int l,int r)
{
	//对a[l]~~~a[r]进行快速排序
	if(l>=r)return;//递归出口 区间中数据量小于等于1个 不需要排
	int p=a[l];//选待排序区间的第一个位置做基准数
	int i=l,j=r;
	while(i<j)
	{
		//前面空出一个位置a[i]，用j从后往前遍历 找比p小的数据 补过去
		while(i<j&&a[j]>p)j--;
		if(i<j)
		{
			//找到了比p小的数 a[j]
			a[i]=a[j];
			i++;
		}
		//后面空出一个位置a[j] 用i从前往后遍历 找比p大的数据 补过去
		while(i<j&&a[i]<p)i++;
		if(i<j)
		{
			//找到了比p大的数 a[i]
			a[j]=a[i];
			j--;
		}

	}
	//i==j
	a[i]=p;
	QSort(a,l,i-1);//p前面的区域 进行快速排序
	QSort(a,i+1,r);
}
int main()
{
	int n,a[105];
	scanf("%d",&n);
	for(int i=1;i<=n;i++)
	{
		scanf("%d",&a[i]);
	}

	QSort(a,1,n);

	for(int i=1;i<=n;i++)
	{
		printf("%d ",a[i]);
	}
	printf("\n");

	return 0;	
}
```

### 堆排序

堆：基于完全二叉树的树形结构，并且满足：

在完全二叉树的基础之上规定:父亲结点的值要比孩子结点的的值大--->大顶堆/大根堆

在完全二叉树的基础之上规定:父亲结点的值要比孩子结点的值小---->小顶堆/小根堆

------>直接用数组存堆:a[i]的父亲是a[i/2],左孩子是a[2*i],不石孩子是a[2*i+1]

   1.建堆:以建立大顶堆为例n=8

53 17 78 9 45 65 87 32

(1)法-:原地调整--->向下调整建堆---->时间复杂度O(n)

先把所有的数据放到数组中,构成一棵完全二叉树,然后再进行调整为大顶堆

从小子树开始调整,最后调整最大的子树(即本身)

最小的子树:只由一个叶子结点构成的子树,不需要调整

从倒数第二小的子树开始调整:依次分别调整以a[n/2]~~~a[1]为根结点的子树即可
在调整以a[i]为根的子树时,以a[2*i],a[2*i+1]为根的子树都已经调整过了

采用向下调整法:从子树的根结点开始调整,根结点和两个孩子比较,最大的做父亲,让根结点和最大的孩子交换,然后继续向下比较,直到该结点比两个孩子大或者没有孩子为止,

(2)法二:边插入边建堆----》向上调整建堆

每次在已经建好的大顶堆上插入一个数据(结点),假设已经有i个数据,新插入的数据的下标就是i+1,让新插入的数据和其父亲比较,如果比父亲大就交换,交换后还有继续循环向上比较,直到没有父亲或者父亲大为止。

堆排序:就是在选择排序的基础之上,引入堆,让乱序区变成堆,从人而快速的找到最大或者最小值。

在乱序区找最大的数往后放。保证乱序区在前,可以构成大顶堆。

(1)先对整个数组用向下调整法建成大顶堆

(2)执行n-1趟排序,第i趟的乱序区[1,n-i+1]

由于乱序区已经是大顶堆了,a[1]就是乱序区最大的数。直接上a[1]和a[n-i+1]交换
交换后,堆顶会变小,继续进行向下调整,把[1.n-il重新建成堆

```c
#include<stdio.h>
#include<stdlib.h>
//堆排序：时间复杂度O(nlogn) 就地排序  不稳定
void Swap(int *x,int *y)
{
	int t=(*x);
	(*x)=(*y);
	(*y)=t;
}

void DownAdjust(int a[],int i,int n)
{//对以a[i]为根堆子树进行向下调整
	int now=i;//当前结点的下标
	int next;//值最大的孩子的下标
	while(2*now<=n)
	{
		next=2*now;//now的左孩子下标
		if(next+1<=n&&a[next+1]>a[next])
		{
			next=next+1;//值最大的孩子的下标
		}

		if(a[now]<a[next])
		{
			Swap(&a[now],&a[next]);
			now=next;//now指向新的被调整的结点
		}
		else break;

	}

}
void UpAdjust(int a[],int i)
{//在大顶堆上 插入a[i]之后 重新调整为大顶堆
	int now=i;//当前结点的下标
	int next;
	while(now>1)
	{
		next=now/2;//now的父亲
		if(a[now]>a[next])
		{
			Swap(&a[now],&a[next]);
			now=next;//now指向新的被调整的结点
		}
		else break;
	}

}
int main()
{
	int n,a[105];
	scanf("%d",&n);
	for(int i=1;i<=n;i++)
	{
		scanf("%d",&a[i]);
		//UpAdjust(a,i);//边插入边建堆---》循环向上调整建堆的总时间复杂度是O(nlogn)
	}
	
	//原地向下调整建堆：先调整小子树---->时间复杂度O(n)
	//枚举被调整的子树的根结点
	for(int i=n/2;i>=1;i--)
	{
		//对以a[i]为根堆子树进行向下调整
		DownAdjust(a,i,n);
	}

	//执行堆排序：时间复杂度O(nlogn)
	int r=n;//乱序区的右边界
	for(int i=1;i<=n-1;i++)//枚举趟数
	{
		//第i趟排序 乱序区是[1,r],排完一趟后r--
		Swap(&a[1],&a[r]);
		r--;
		//把a[1]~~a[r]重新调整为大顶堆：此时只有堆顶变小了 只需要对堆顶执行向下调整
		DownAdjust(a,1,r);
	}
	

	
	for(int i=1;i<=n;i++)
	{
		printf("%d ",a[i]);
	}
	printf("\n");
	return 0;
	
}
```

### 归并排序

序列还要再放回原位置。

把两个有序序列合并成一个有序序列:枚举比较合并

用两个下标i和j,分别从两个序列的开头位置,a[i]和a[j]比较,其中小的一个就是当前待排序数据中的最小值,他放到有序序列中。当一个下标越界时,只需要把另外一个序列列中的剩余数据全部依次放到有序序列中即可

```
#include<stdio.h>
#include<stdlib.h>
//归并排序：时间复杂度O(nlogn) 稳定  不是就地排序
void MergeSort(int a[],int l,int r)
{//对a[l]~~~a[r]进行排序
	if(l>=r)return;//递归出口，只有一个数据时，是不需要排序的，本身就有序
	int mid=(l+r)/2;//l~~~mid.     mid+1~~~~r
	//a[l]~~~a[mid]排成升序
	MergeSort(a,l,mid);
	//a[mid+1]~~~a[r]排成升序
	MergeSort(a,mid+1,r);
	
	//把两个有序序列合并成一个有序序列：枚举 比较 合并
	int i=l,j=mid+1;
	int t[105],k=0;//t数组临时存储 合并后的有序序列
	while(i<=mid&&j<=r)
	{
		if(a[i]<=a[j])
		{
			t[k++]=a[i];
			i++;
		}
		else
		{
			t[k++]=a[j];
			j++;
		}
	}
	while(i<=mid)
	{//前一半如果还剩数据 把剩余数据放到t数组中
		t[k++]=a[i];
		i++;
	}
	while(j<=r)
	{//后一半如果还剩数据 把剩余数据放到t数组中
		t[k++]=a[j];
		j++;
	}
	//t[0]~~~t[k-1] 放回到 a[l]~~~a[r]
	for(i=0;i<k;i++)
	{
		a[l+i]=t[i];
	}

}
int main()
{
	int n,a[105];
	scanf("%d",&n);
	for(int i=1;i<=n;i++)
	{
		scanf("%d",&a[i]);
	}

	MergeSort(a,1,n);
	
	
	for(int i=1;i<=n;i++)
	{
		printf("%d ",a[i]);
	}
	printf("\n");
	return 0;
	
}
```

### 哈希查找

哈希查找:不再基于"比较操作",对于每一个数据,都可以通过某种方式直接计算出其地址(位置)。---》本质上是建立了数据到地址的映射

哈希存储:建立了数据到地址的映射,每个数据都要存放在与其对应的地址中。根据哈希存储建立哈希表。

哈希查找:就是在哈希表上进行的查找,不基于比较操作,而是直接去计算地址。

哈希函数:可能是数学上的一个函数,也可能是无法用算式表示的某种计算流程。

哈希查找的前提:建立哈希表,在哈希表上进行查找。

哈希冲突:由于哈希函数的原因,有可能导致多个数据对应同一个地址,该现象称为哈希冲突。我们要尽可能的减少哈希冲突。

1.先确定哈希函数和解决哈希冲突的方法

2.根据给出的公式和数据建立哈希表

3.可以进行哈希查找

假设有n个数据,哈希表表长为mm>=n
重点1:哈希函数怎么确定?/常用的哈希函数有哪些?/怎么构造哈希函数?

1.直接定址法:直接选取某个线性函数做哈希函数。

H(key)=a*key+b;a和b是常数,key是数据/关键字,H(key)是位置

好处:简单

缺点:如果数据不连续会产生很大空位,浪费空间

2.除留余数法

Hey(key)=key%p

p:取一个不大于m并且最接近m的一个质数

3.数字分析法:

当我们的数据由很多数位组成时,可以观察数据的每个数位上数字的分布特点,选取其中的几位做地址即可。

4.平方取中法：key*key 取中间几位做地址

重点2:如果产生了哈希冲突如何解决?

1.链地址法(拉链法)---》扩容

表中每个位置指向一个链表,把数据插入到链表中。也就是产生冲突的数据,组成链表都放在同一个位置。

2.开放定址法----》进行二次计算,算一个新位置

通过哈希函数算出地址H(key),如H(key)位置冲突了,也就是已经有别的数据了,我们通过下式算一个新地址:Hi= (H(key)+di) %m

Hi是新地址

H(key)是第一次算的地址,也就是有冲突的地址

di是一个增量序列

m是表长

(1)线性探测法:di=1,2,3.....m-1

产生聚集(堆积)现象----》降低查找效率

(2)平方探测法:di=1^2-1^2 2^2 -2^2 3^3-3^3.......k^22-k^2k<=m/2-------->m必须可以写成4*k+3至少可以探测到一半的空间

(3)双散列法

di=i*(key ) i=1,2,3...

(4)伪随机法

di=伪随机数序列

### B树

多路平衡查找/搜索树：用于数据库管理，一个结点的大小是一页的大小，因此一个节点可以存放多个数据，具有顺序性，绝对平衡

2-3-树：--->度为3-->3阶B树

​	2-结点：结点内部可以存放1个数据，具有2个子结点。

​	3-结点：结点内部可以存放2个数据，具有3个子结点。

2-3-4-树：-->度为4-->4阶B树

 	2-结点：结点内部可以存放1个数据，具有2个子结点。

​	 3-结点：结点内部可以存放2个数据，具有3个子结点。

4-结点：结点内部可以存放3个数据，具有4个子结点。

m-结点：结点内部可以存放m-1个数据，具有m个子结点。

性质：

1.绝对平衡：叶子结点都在同一层

​	叶子结点：最终端结点的空孩子

​	终端结点：最下面一层没有孩子的结点

2.具有顺序性：结点内部的多个数据顺序排列，结点之间也有顺序性

3.树中每个结点最多有m个子结点，m-1个数据

4.树中每个非根结点最少有ceil(m/2)个子结点，ceil(m/2)-1个数据，根结点最少2个结点，1个数据



B树的操作：查找 插入 删除

假设B树中的数据是升序排列，结点中的数据域要存放多个数据就搞成数组

1.查找：基于顺序性，查找关键字x是否在B树中，返回位置（结点p地址,数据数组的下标）

从根结点开始进行查找，每当查找一个结点时，先在结点内部进行顺序查找（折半查找），找的第一个大于等于x的位置i。如果i位置的数据刚好等于x，查找成功，返回该结点的地址以及位置i,如果i位置的数据大于x，就往i位置左边的孩子结点进行查找，直到找到x或走到空结点为止。

2.插入：在B树中插入关键字x（默然不存在重复数据）

回溯插入法：

（1）先查找x的入位置（某个终端节点pre，数组的下标）

执行查找x的操作,查找过程中要用一个pre指针一直记录父亲结点,最终查找到叶子洁点时,pre指向的结点就是x应该在的结点。假设pre结点中数据数组的i位置是第一个大于x的位置,x就应该插入到i位置。

(2)插入

(3)结点pre中多了一个数据其数据的个数就可能超过上限(m-1),因此要判断是否需要调整:

​	如果插入x后,数据个数<=m-1,不需要调整,结束。

​	如果插入x后,数据个数>m-1(也就是m个),需要调整:循环分裂上传

循环分裂上传:

从下标s=ceil(m/2)位置分开,data[1]~data[s-1]留在原结点中	data[s]插入到父亲结点	data[s+1]~~data[m]给新结点ap(同时每个对应的左右孩子也要给ap)



​	data[s]插入到父亲结点中,父亲结点也多了一个数据,其数据的个数也可能超过上限(m-1),就需要对父亲结点继续进行调整。继续循
环。直到某个节点接收来自孩子的一个数据之后数据个数不超上限就停止。或者一直循环到根结点,根结点接收来自孩子的一个数据
之后,也超过上限,就把根结点分裂,再添加一个新的根结点就停止。

主动分裂插入法：不在回溯，在查找过程中把有分裂风险（有m-1个1数据）的节点提前分裂

3.删除:在B树中删除数据x-------》少一个数据,对应也要少一个孩子

(1)先找到x所在的位置《结点z 	data[i]》

(2)执行删除下操作:分类讨论

情况1:z是终端结点,其孩子都是空孩子,删除一个数据之后不需要对孩子进行处理

直接在结点z的数据数组中删除data[i]:data[i+1]~~data [n] (假设有n个数居)挨个前移

此时z中少一个数据,数据量可能低于下限ceil(m/2)-1。进行调整:

看相邻的亲兄弟是否够借,够借则借不够借则合并。

借关键字:如果存在一个相邻的亲兄弟,数据的个数多于下限,找他借一个数据(对应的孩子也得跟过来)。

为了保证顺序性,找左边兄弟借最大值,找右兄弟借最小值,并且要通过父亲结点

都不够借,合并:选一个兄弟合并成一个结点,合并时要把父亲中对应的一个数据也合并进来。

父亲结点少一个数据少一个孩子,再对父亲结点进行要调整。循环向上调整,直到父亲结点不需要调整或者把根结点唯一的数据合并,合并后根结点唯一的一个孩子做新的根结点。

情况2:z是非终端结点,其孩子不是空孩子

找x的中序遍历后继数据x1(假设x1再结点k中),k一定是终端结点,就用x1覆盖x,问题转化为去k中删除x1,即情况1

```c++
BTNode* NewRoot(BTNode* p,int k,BTNode* ap)
{
	BTNode* s=(BTNode*)malloc(sizeof(BTNode));
	//if(s==NULL)
	s->key[1]=k;
	s->ptr[0]=p;
	s->ptr[1]=ap;
	s->fa=NULL;
	s->keynum=1;
	if(p!=NULL)p->fa=s;
	if(ap!=NULL)ap->fa=s;
	return s;
}
void Insert(BTNode* z,int i,int k,BTNode* ap)
{//把k插入到z结点的key[i]位置 ap插入到z结点的ptr[i]位置
	//把key[i]~~key[keynum]后移 空出key[i]
	//把ptr[i]~~ptr[keynum]后移 空出ptr[i]
	for(int j=z->keynum;j>=i;j--)
	{
		z->key[j+1]=z->key[j];
		z->ptr[j+1]=z->ptr[j];
	}
	z->key[i]=k;
	z->ptr[i]=ap;
	if(ap!=NULL)ap->fa=z;
	z->keynum++;//注意
}
void Split(BTNode* z,int s,BTNode* &ap)
{//分裂
	//z结点 从s位置一分为2
	//key[1]~~key[s-1]留在z中 key[s+1]~~key[m]给ap
	//ptr[0]~~ptr[s-1]留在z中,  ptr[s]~~~ptr[m]给ap 
	ap=(BTNode*)malloc(sizeof(BTNode));
	//if(ap==NULL)
	//先处理ptr[s]
	int j=0;//ap结点中数组的下标
	ap->ptr[0]=z->ptr[s];
	if(z->ptr[s]!=NULL)z->ptr[s]->fa=ap;

	for(int i=s+1;i<=m;i++)
	{
		j++;
		ap->key[j]=z->key[i];
		ap->ptr[j]=z->ptr[i];
		if(z->ptr[i]!=NULL)z->ptr[i]->fa=ap;//父亲变成ap
	}
	ap->keynum=j;//j==m-s
	z->keynum=s-1;
}
void InsertBTree(BTree &t,int k,BTNode* z,int i)
{///在结点z的数据数组中的i位置插入k
	if(t==NULL)
	{//空树插入 创建一个新的根结点
		t=NewRoot(NULL,k,NULL);
		return ;
	}
	//非空树插入：在结点z中 key[i]位置插入k，同时孩子数组中也要插入一个孩子ap
	BTNode* ap=NULL;//多一个孩子ap
	int s=0;//分裂位置
	while(1)
	{
		//把k插入到z结点的key[i]位置 ap插入到z结点的ptr[i]位置
		Insert(z,i,k,ap);
		if(z->keynum<=m-1)
		{
			break;//插入后不超过上限，结束
		}
		else
		{//分裂上传
			s=(m+1)/2;//等同于ceil(m/2);
			k=z->key[s];//k保存插入到父亲结点中的数据
			Split(z,s,ap);
			if(z->fa!=NULL)
			{//把k和ap 插入到z到父亲中
				z=z->fa;//z指向新的被插入数据的结点
				i=SearchNode(z,k);//查找插入位置
			}
			else
			{//如果z是根结点
				t=NewRoot(z,k,ap);
				break;
			}

		}
	}
	
}

void Remove(BTNode* z,int i)
{
	//从结点z中删除数据key[i]和ptr[i]
	//把key[i+1]~~key[keynum]挨个前移
	//把ptr[i+1]~~ptr[keynum]挨个前移
	for(int j=i+1;j<=z->keynum;j++)
	{
		z->key[j-1]=z->key[j];
		z->ptr[j-1]=z->ptr[j];
	}
	z->keynum--;
}
void Borrow(BTNode* z,BTNode* lbro,BTNode* rbro,BTNode* pa,int i)
{//z是pa的孩子 z是pa->ptr[i],lbro和rbro是z的兄弟
	if(lbro!=NULL&&lbro->keynum>minn)
	{//左兄弟存在 并且够借 找左兄弟借
		//z结点腾出key[1]和ptr[0]
		for(int j=z->keynum;j>=1;j--)
		{
			z->key[j+1]=z->key[j];
		}
		for(int j=z->keynum;j>=0;j--)
		{
			z->ptr[j+1]=z->ptr[j];
		}
		//pa->key[i]给z，放到z->key[1]位置
		//lbro->key[lbro->keynum]给pa，放到pa->key[i]位置
		//lbro->ptr[lbro->keynum]给z，放到z->ptr[0]位置
		z->key[1]=pa->key[i];
		pa->key[i]=lbro->key[lbro->keynum];
		z->ptr[0]=lbro->ptr[lbro->keynum];
		if(lbro->ptr[lbro->keynum]!=NULL)lbro->ptr[lbro->keynum]->fa=z;//注意改变父亲
		lbro->keynum--;
		z->keynum++;
	}	
	else
	{//否则 找右边兄弟够借
		//pa->key[i+1]给z ，放到z->key[z->keynum+1]位置
		//rbro->key[1]给pa，放到pa->key[i+1]位置
		//rbro->ptr[0]给z  放到z->ptr[z->keynum+1]位置
		z->key[z->keynum+1]=pa->key[i+1];
		pa->key[i+1]=rbro->key[1];
		z->ptr[z->keynum+1]=rbro->ptr[0];
		if(rbro->ptr[0]!=NULL)rbro->ptr[0]->fa=z;
		//处理右边兄弟
		for(int j=2;j<=rbro->keynum;j++)
		{
			rbro->key[j-1]=rbro->key[j];
		}
		for(int j=1;j<=rbro->keynum;j++)
		{
			rbro->ptr[j-1]=rbro->ptr[j];
		}
		z->keynum++;
		rbro->keynum--;
	}
}
void Meger(BTree &t,BTNode* &pa,BTNode* &x,BTNode* &y,int yi)
{//	pa是x和y的父亲，x靠左 y靠右
	//把y合并到x里面去，即把y中的数据和孩子都给x 由于y中是数据比x中的大 顺着放即可
	//y的下标是yi 意味着 y是pa->key[yi]的右边孩子
	//pa->key[yi]给x 放到x->key[x->keynum+1];
	x->key[x->keynum+1]=pa->key[yi];
	//先处理y的第0个孩子 给x，放到x->ptr[x->keynum+1]
	x->ptr[x->keynum+1]=y->ptr[0];
	if(y->ptr[0]!=NULL)y->ptr[0]->fa=x;
	x->keynum++;

	//y->key[1]~~~y->key[y->keynum]给x 顺着放
	//y->ptr[1]~~~y->ptr[y->keynum]给x 顺着放
	for(int j=1;j<=y->keynum;j++)
	{
		x->keynum++;
		x->key[x->keynum]=y->key[j];
		x->ptr[x->keynum]=y->ptr[j];
		if(y->ptr[j]!=NULL)y->ptr[j]->fa=x;
	}

	//处理y结点
	free(y);
	y=NULL;
	pa->ptr[yi]=NULL;
	//处理父亲结点
	Remove(pa,yi);//删除pa结点中的key[yi] ptr[yi]
	//判断父亲结点是否需要调整
	if(pa->fa==NULL)
	{
		//pa是根结点
		if(pa->keynum<1)
		{
			t=x;//根指针指向唯一的一个结点
			x->fa=NULL;
			free(pa);
			pa=NULL;
		}
	}
	else
	{
		//pa是不是根结点
		if(pa->keynum<minn)
		{
			Restore(t,pa);
		}
		
	}

}

{

	BTNode* pa=z->fa;//pa是z的双亲结点

	{

		{
			break;
		}
	}
	//z是pa->ptr[i]. z的左兄弟是pa->ptr[i-1]  z的右兄弟是pa->ptr[i+1]
	BTNode* lbro=NULL;//z的左兄弟
	BTNode* rbro=NULL;//z的右兄弟
	if(i>0)lbro=pa->ptr[i-1];
	if(i<pa->keynum)rbro=pa->ptr[i+1];

	if((lbro!=NULL&&lbro->keynum>minn)||(rbro!=NULL&&rbro->keynum>minn))
	{//至少有一个兄弟够借
		Borrow(z,lbro,rbro,pa,i);//借关键字

		if(lbro!=NULL)
```

### B+树

 m阶B+树的性质

1.非终端节点中只存放关键字，不存放关键字对应的数据的地址，终端结点中存放所有的关键字以及对应的数据的地址，上层结点的索引

2.终端结点之间用指针相连形成类似链表的样子

3.结点中关键字的个数和孩子节点的个数相等

4.B+树有两个阶，分别控制终端节点和非终端结点，但是我们考研统一就是m阶B+树

5.查找操作一定要找到终端结点

6.B+树具有顺序性和绝对平衡

7.每个节点最多有m棵子树

8.非叶根结点最少有两棵子树，其他的非终端结点最少有ceil(m/2)棵子树

9.叶根结点最少有1个数据。



B+树的操作：查找 插入 删除

单点查找：查找某个关键字。和B树的查找类似，现在结点内部查找，找的第一个大于等于k的位置，如果不是终端结点，继续去对应的孩子结点中查找，直到终端节点为止

区间查找：查找某个区间内的所有关键字[13,60]之间的数据，先对左边界进行查找，在某个终端节点中找的第一个大于等于左边界的数据，然后顺着终端节点进行遍历即可

插入操作：插入数据k，和B树类似。注意：终端结点分裂之后要维护next指针，如果插入的是最大值，要向上修改父亲节点的数据，上传时并不是直接把孩子的数据给父亲而是把新结点的最大值提取给父亲中做索引

优化：父亲节点 不在保存最右边孩子的索引，如果插入的是最大值，就不需要向上修改父亲结点的数据

删除操作：删除数据K和B树类似；

```c++
int binary_search(KEY* keys, KEY key, int left, int right, int* index)
{
	int mid;
	while (left <= right)
	{
		mid = (left + right) / 2;
		if (item_cmp(keys[mid],key) > 0)
		{
			right = mid - 1;
		}
		else if (item_cmp(keys[mid], key) < 0)
		{
			left = mid + 1;
		}
		else
		{
			*index = mid;
			return 1;
		}
	}
	*index = left;
	return 0;
}

		}

			return 0;
		}
		//拷贝数据

		temp = node->keys[mid];
		if (node->child == NULL)
		{
			node2->keynum = node->keynum - mid;

			memcpy(node2->data, node->data + mid, sizeof(KEY) * (node2->keynum));
			node2->next = node->next;
			node->next = node2;

		}
		else

			memcpy(node2->child, node->child + mid + 1, sizeof(bplus_node_pt) * (node->keynum - mid));

		node->keynum = mid;

		/*插入父节点*/
		parent = node->parent;
		if (parent == NULL)
		{
			//生成一个新的根节点
			parent = bplus_node_new_internal(tree->max);
			if (parent == NULL)
			{
				return 0;
			}
			parent->child[0] = node;
			node->parent = parent;
			tree->root = parent;
		}
		
		/*增加数据 右子树*/
		for (i = parent->keynum; i > 0 && item_cmp(parent->keys[i - 1], temp) > 0; i--)
		{
			parent->keys[i] = parent->keys[i - 1];
			parent->child[i + 1] = parent->child[i];
		}

		parent->keys[i] = temp;
		parent->child[i + 1] = node2;
		parent->keynum++;

		node2->parent = parent;

		//回溯 向上继续判断
		node = parent;


	}
	return 1;
}


int bplus_tree_insert(bplus_tree_pt tree, KEY key, VALUE value)
{
	bplus_node_pt node;
	int ret,index;
	if (tree->root == NULL)
	{
		node = bplus_node_new_leaf(tree->max);
		if (node == NULL)
		{
			return 0;
		}
		tree->root = node;
	}

	node = tree->root;
	//查找叶子结点
	while (node->child != NULL)
	{
		ret = binary_search(node->keys, key, 0, node->keynum - 1, &index);
		if (ret == 1)
		{
			index++;
		}
		node = node->child[index];
	}

	ret = binary_search(node->keys, key, 0, node->keynum - 1, &index);
	if (ret == 1)
	{
		//这个结点已经存在了
		return 0;
	}
	_bplus_tree_insert(tree, node, key, value);
	return 1;
}

/*
合并结点元素的左右两个子节点
*/
void _bplus_node_merge(bplus_node_pt node, int index)
{
	bplus_node_pt left, right;
	left = node->child[index];
	right = node->child[index + 1];
	if (left->child != NULL)
	{
		/*修改左子节点*/
		left->keys[left->keynum] = node->keys[index];
		memcpy(left->keys + left->keynum + 1, right->keys, sizeof(KEY) * (right->keynum));
		
		for (int i = 0; i <= right->keynum; i++)
		{
			right->child[i]->parent = left;
			left->child[left->keynum + i + 1] = right->child[i];
		}

		left->keynum = left->keynum + right->keynum + 1;
	}
	else
	{
		memcpy(left->keys + left->keynum, right->keys, sizeof(KEY) * (right->keynum));
		memcpy(left->data + left->keynum, right->data, sizeof(VALUE) * (right->keynum));

		left->keynum = left->keynum + right->keynum;;
	}

	/*修改父节点*/
	for (int i = index; i < node->keynum - 1; i++)
	{
		node->keys[i] = node->keys[i + 1];
	}

	for (int i = index + 1; i < node->keynum; i++)
	{
		node->child[i] = node->child[i + 1];
	}
	node->keynum--;

	/*释放右节点*/
	free(right->keys);
	free(right->data);
	free(right->child);
	free(right);

}

void _bplus_tree_delete(bplus_tree_pt tree, bplus_node_pt node, int index)
{
	bplus_node_pt parent, sibling;
	/*先删除叶子结点的指定的值*/
	for (int i = index; i < node->keynum - 1; i++)
	{
		node->keys[i] = node->keys[i + 1];
		node->data[i] = node->data[i + 1];
	}
	node->keynum--;
	parent = node->parent;
	while (node->keynum < tree->min  &&  parent!= NULL)
	{
		/*寻找到当前结点在父节点当中的位置*/
		for ( index = 0; index <= parent->keynum && parent->child[index] != node; index++);
		if (index > parent->keynum)
		{
			//在他的父节点中没找到这个孩子
			return;
		}
		if (index == 0)
		{
			//如果是第一个结点  没有左兄弟 只有右兄弟
			sibling = parent->child[1];
			if (sibling->keynum > tree->min)
			{
				//迁移数据
				if (node->child == NULL)
				{
					//叶子结点的迁移
					_bplus_leaf_left_rotate(parent, 0);
				}
				else {
					_bplus_internal_left_rotate(parent, 0);

				}

			}
			else
			{
				/*合并兄弟*/
				_bplus_node_merge(parent, 0);
			}
		}
		else
		{
			/*
			如果结点是父节中的第index个子节点，兄弟是第index - 1
			中间的分割元素是父节点中的第index - 1个元素
			*/
			sibling = parent->child[index - 1];
			if (sibling->keynum > tree->min)
			{
				//从左兄弟迁移数据
				if (node->child == NULL)
				{
					//叶子结点的右旋转
					_bplus_leaf_right_rotate(parent, index - 1);
				}
				else {
					//内部结点的右旋转
					_bplus_internal_right_rotate(parent, index - 1);
				}

			}
			else
			{
				/*合并兄弟*/
				_bplus_node_merge(parent, index - 1);
			}


		}

		node = parent;
		parent = node->parent;
		
	}

	if (tree->root->keynum == 0 && tree->root->child != NULL)
	{
		node = tree->root;
		tree->root = node->child[0];
		free(node->keys);
		free(node->data);
		free(node->child);
		free(node);
	}



}
```

### 红黑树

RBT：基于二叉排序树表达并实现3阶或4阶B树的数据结构---》是通过对3阶或四阶B树进行按序才分得到的，并且给结点加颜色以区分，区分使原本就有的节点，还是从父亲节点中拆分下来的；

由于红黑树是从B树拆分下来的，也就是B树是其灵魂，因此我们对红黑树进行操作后，如果不确定是否满足红黑树的概念，可以先将其还原回B树的样子，然后进行正确的拆分，对比两颗红黑树的区别即可

RBT的性质：

1.红黑树每个节点都是黑色或红色的

2.根节点一定是黑色的

3.叶子结点也一定是黑色的（终端结点的孩子）

4.不存在两个相邻的红色结点（红色节点的父亲和孩子一定是黑色的）

5.对于每个节点，从该节点到其下面的任意一个叶子节点的简单路径上，黑色节点的数目是一样的（因为原本B舒适绝对平衡的，黑色节点原本B树的节点）

6.满足顺序性--》中序遍历有序

左根右 根叶红 不红红 黑路同

结论一：从根结点到叶子结点的最长路径不超过最短路径的2倍

假设原来的B树高度为x。原来的B树从根结点到某一个叶子的路径就由×+1个结点组成路径长度就是x最短路径就是只由黑色结点组成途径x+1个结点长度为x最长路径,就是除叶子结点以外其他的x个黑色结点都向下拆分一个个红色孩子,路径经过的结点数2x+1个,路径长度就是2x-------》

可以得出红黑树的平衡性:某个节点的左右子树高度,相差2音左右。

结论2:有n个内部结点的红黑树其高度h<=2log(n+1)

某个节点的黑高b h:从某一结点出发,到其下任意一个叶子结点的路径上所经过的黑色结点的个数(不算起点)。根结点的黑高称为树的黑高。

红黑树的黑高就是原本B树的高度。

证明:假设红黑树的黑高为b h,高度为h,一共有n个内部结点

b h<=h<=2bh<=2log(n+1)

2^b h-1<=n

2b h<=2log(n+1)



红黑树的操作：

1.查找：同BST的查找过程

2.插入操作:在红黑树上插入一个数据x,假设数据x放到结点z中进行插入
(1)新建一个结点z,数据x放到结点z中,去执行BST的插入操作,把结点点z插入到红黑树中,此时就满足了顺序性
(2)结点z的初始颜色:红色
黑色:一定不满足"黑路同",每次插入之后都需要进行调整。
红色:如果该结点刚好是根结点,就需要调整,要把它变成黑色。-----》可能不满足"根叶黑"
如果该结点的父亲刚好也是红色的也需要调整-----
-------》可能不满足"不红红"
(3)插入z之后,如果不满足"根叶黑"或者"不红红"怎么调整?
情况一:z是红色的,如果是空树插入z,z做根结点,此时不满足"根叶黑"----->要把它变成黑色。

```c
				}
				break;//叔叔是黑色不需要循环向上调整，直接跳出循环

			}

		}
		else//p是g的左孩子

			u=g->r;//叔叔，可能是空的
			if(u!=NULL&&u->color==RED)
			{//叔叔是红色的

				{//LR

					g->color=RED;

				}

			}

		}
	}
	if(p==NULL)root->color=BLACK;//此时z是根结点 是红色的 就需要把根结点重新变黑
	return root;

}
RBTree Insert(RBTree root, int x)
{
	//特殊情况 空树插入
	if(root==NULL)
	{
		root=CreateNode(x,NULL);
		root->color=BLACK;//根结点变为黑色
		return root;
	}
	//非空树插入
	//1.执行BST插入过程：找到x的父亲结点，然后新建结点z 把x放到z中 插入到红黑树中
	RBTNode* z=root;
	RBTNode* zp=NULL;//查找过程中 zp指向z的父亲
	while(z!=NULL)
	{
		zp=z;
		if(x<z->data)z=z->l;
		else z=z->r;
	}
	z=CreateNode(x,zp);
	if(x<zp->data)zp->l=z;
	else zp->r=z;
	//判断是否需要调整：z是红色的 如果zp也是红色的 就不满足“不红红”，需要调整
	if(zp->color==RED)
	{
		root=In_Fixup(root,z);
	}
	return root;
}

RBTree Delete(RBTree root,int k)
{
	//先找k所在的结点y
	RBTNode* y=Find(root, k);
	if(y==NULL)
	{//k不存在
		printf("该数据不存在，无法删除\n");
		return root;
	}
	//二叉排序树的删除
	//如果y的度是2 找中序遍历前驱或者后继 转化为删除前驱或者后继
	if(y->l!=NULL&&y->r!=NULL)
	{
		RBTNode* q=y->r;
		while(q->l!=NULL)q=q->l;
		//q是y的后继，q的度一定是1/0
		y->data=q->data;
		//y指针指向被free的结点
		y=q;
		q=NULL;//防止q成为野指针

	}
	//此时 被free的结点y 的 度 一定是1/0
	RBTNode* p=y->pa;//p是y的父亲 p可能为NULL
	RBTNode* x=NULL;//x指向y的唯一的孩子
	if(y->l!=NULL)x=y->l;
	else x=y->r;
	//处理p和x的关系
	if(x!=NULL)x->pa=p;//x的父亲变成p
	if(p==NULL)
	{//y是根结点 删掉y之后 x变成新的根结点
		root=x;
	}
	else
	{//y的父亲p不为空 删掉y之后 x变成p的孩子
		if(y==p->l)p->l=x;
		else p->r=x;
		
	}
	int yc=y->color;//记录y的颜色
	free(y);
	y=NULL;

	if(root==NULL)return root;//删除y之后 变成空树 不需要调整 直接返回

	if(yc==BLACK)//y是黑色才需要调整
	{
		
		root=DE_Fixup(root,x,p);//调整 重新恢复为红黑树
		
	}
	return root;

}
```

## 动态规划

DP的基本思想：一个大问题可以分解为诺干个小问题，并且各个问题的解题思路 是类似的，可以通过小问题的解来得到原问题的解，并且小问题之间往往不是独立的

求解动态规划问题的一般思路:
1.分析提议确定是否属于动态规划问题:最优子结构性质+重叠子问题性质
2.确定状态数组dp
(1)经验/天赋
(2)技巧:把问题改成陈述句描述:其中的参数就是状态数组的的下标,答案就是状态数组对应的值
问题:求第n项的值是几?----》陈述句第n项的值是x。
dp[n]=x----->第n项的值是x。
(3)先用记忆化搜索的思路自上而下分析,写一个简单的递归的的代码:状态数组/状态转移公式
状态数组:记忆化数组
状态转移公式:递归调用处的语句

3.确定状态转移公式
(1)经验/天赋
(2)技巧:求中间状态法
根据题目可以分析出初始状态。假设前i-1个状态都已经知道,求i个状态,也就是分析一下第i个状态和哪些状态有关系。
dp[i]=dp[i-1]+dp[i-2]//状态转移公式
4.写代码:基于循环
状态数组
初始状态:手推得到
根据状态转移公式由初始状态dp[0]依次得到中间状态dp[i]最后得到最终状态dp[n]

## 字符串匹配：KMP算法

 字符串:由0个或多个字符组成的连续序列。串中字符的个数称为该串的长度。字符通常用数组的形
式保存。
char s[]="abcd";---->字符串:末尾有一个隐含的'\0"
char a[={'a','b','d'};------->字符数组
子串:一个字符串中,拿出连续的一段,称为该串的子串

前缀子串:从字符串的第一个字符开始,到后面任意一个字符结束(结束位置不能是最后一个位置)该范围内的就是前缀子串。

后缀子串:除第一个位置以外,从任意一个位置开始,到最后一个位置结束,该范围内的就是后缀子串

把长的一样的一对前缀子串和后缀子串称为相同前后缀,其中长度最长的相同前后缀称为最长相同
前后缀。
如果一个字符串s有多个相同前后缀:假设其中两个相同前后缀分别是子串x和子串yx比y长
y一定也是x的相同前后缀。------>短的相同前后缀y一定是长的相同前后缀x的相同前后缀

字符串匹配:给出两个字符串p和s把p称为主串,s称为模式串。问主串p中是否存在一段连续的序
列和s匹配上。------》s是不是p的一个子串
暴力匹配:尝试从p的每个位置开始和s进行匹配比较。

暴力

暴力优化：优化之后:先对模式串s算next@再进行匹配
基于动态规划的思路去写:
next[]看成状态数组:是s[0]~~s[-1]的最长相同前后缀的长度
nextlj-1]:是s[0]~~s[j-2]的最长相同前后缀的长度
假设next[-1]=xs[0]~~s[-2]的最长相同前后缀的长度为x
【0,j-1】的后缀比【0,j-2】的后缀多一个s[-1],前缀也补
一个s[x]
如果s[x]==s[-1][0,j-1]的最长相同前后缀的长度为x+1
如果s[x]!=s[-1]在[0j-2]短的相同前后缀【0,×】基础上推,
x=next[x]
